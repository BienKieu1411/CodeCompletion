SAFETY GATES
01 / INPUT

Context đến từ đâu?

Active file mang file_path và left_context. Baseline retriever được gọi bên ngoài rồi truyền retrieved_chunks vào. pool_files được dùng riêng để tìm spec/CSSI.

02 / DRAFT

Pass 1 và cổng bảo vệ

Generator tạo draft z₀. CADRE so dòng đầu tiên với tối đa 6 retrieved chunks và 80 dòng cuối của left context. Similarity ≥ 0.95 thì trả z₀; nếu không, parser trích receiver, callees và token stems.

03 / SPEC

Intent → target API

TargetSpecResolver dò khai báo trong repo pool bằng candidate tokens và giữ tên class trong signature. Nếu top-3 retrieved chunks đã có definition chính, hoặc không tìm thấy spec, pipeline trả draft mà không chạy pass 2.

04 / REFINE

Ghép prompt lượt hai

Channel A coalesce raw chunks theo filepath; CSSI là tùy chọn; target spec thành banner; tiếp theo là file path và suffix left context. Cùng generate_fn được gọi lần nữa để sinh completion.

WINDOW SLACK GUARD · DEFAULTS TRONG CODE

W=3072 · B_mid=1536 · headroom=64

Slack ≥ 0: pass 2 đặt cross-file cap 2304, min-left parameter 256. Slack < 0: cap 1536, min-left parameter 1024. PromptBuilder còn khấu trừ path, CSSI/spec và headroom khi lắp prompt.
