# S20 — RepoHyper

- **Publication:** FORGE 2025.
- **Task:** Repository-level code completion.
- **Method:** Search–expand–refine on semantic repository graphs: retrieve seed nodes, expand graph neighborhoods/path patterns, and refine/rank candidates.
- **Use here:** Recent graph prior art immediately before the 2026 papers. Supports the conclusion that a generic graph-plus-reranker is not novel enough.
- **Limitations:** Graph methods require index construction and relation extraction; test whether relation features add value beyond sparse and dense ranking under the project's one-pass budget.
- **Short exact quote:** “Search-Expand-Refine on Semantic Graphs”
- **Source:** [FORGE 2025 DOI](https://doi.org/10.1109/Forge66646.2025.00009).
