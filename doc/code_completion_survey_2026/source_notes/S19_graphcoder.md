# S19 — GraphCoder

- **Publication:** ASE 2024 Research Papers.
- **Task:** Repository-level completion.
- **Method:** Code Context Graph includes control-flow, data-flow, and control/data-dependence information and supports coarse-to-fine retrieval.
- **Use here:** Prior art for explicit graph relations and graph-guided retrieval; motivates a focused distinction between graph existence and relation-aware ranking for FIM.
- **Limitations:** Reported graph-construction/retrieval cost and task settings differ; do not infer the graph helps under every generator or chunk budget.
- **Short exact quote:** “Coarse-to-fine Retrieval Based on Code Context Graph”
- **Source:** [ASE 2024 paper record](https://conf.researchr.org/details/ase-2024/ase-2024-research/46/GraphCoder-Enhancing-Repository-Level-Code-Completion-via-Coarse-to-fine-Retrieval-B).
