# S11 — One Size Does Not Fit All

- **Publication:** FSE 2026 Research Papers.
- **Task:** Comparative study of context engineering for repository-level code generation; adjacent to FIM completion.
- **Finding used in this survey:** The study compares multiple context strategies and highlights effectiveness/efficiency trade-offs, including static analysis versus broad navigation/context collection.
- **Use here:** A reminder to report retrieval quality jointly with latency and context cost, and not assume that a longer or more exhaustive context is best.
- **Limitations:** Different task/backbones; this survey does not use it as a direct retrieval performance baseline.
- **Short exact quote:** “One Size Does Not Fit All”
- **Source:** [FSE 2026 paper record](https://conf.researchr.org/details/fse-2026/fse-2026-research-papers/65/One-Size-Does-Not-Fit-All-Revisiting-Code-Context-Engineering-for-Repository-Level-C).
