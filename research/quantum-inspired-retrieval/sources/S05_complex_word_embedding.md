# S05 — Quantum-Inspired Complex Word Embedding

- **Authors / year:** Chen et al., ACL 2018 workshop paper.
- **Type:** ACL Anthology conference/workshop paper.
- **Source:** [ACL Anthology](https://aclanthology.org/W18-3006/) · [PDF](https://aclanthology.org/W18-3006.pdf).
- **Credibility / recency / bias risk:** 4 / 1 / 3.

## Findings relevant to this project

The paper assigns complex-valued representations to words and uses relative phase in composition. It reports gains on binary sentence classification tasks, providing an older NLP example where phase is used to represent compositional interaction rather than only vector distance.

**Short quote:** “subscribe a relative phase to each word”.

## Transfer boundary

This motivates phase-conditioned interactions as a modeling primitive, but it is neither retrieval nor source-code evaluation. It cannot support a quantitative expectation of beating AlignCoder.
